Protégez votre compte avec un code de récupération

Votre Espace sera chiffré sur cet appareil avant d'être envoyé. Pour l'ouvrir sur un autre appareil, il faudra ce code de récupération. Nous ne le connaissons pas : sans lui, vos données sauvegardées ne pourront pas être récupérées sur un nouvel appareil.
